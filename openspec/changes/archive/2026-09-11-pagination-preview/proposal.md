# US-34 预览分页与一致性校验

## Why
技术简历具有强烈的「一页纸（或严格两页纸）」硬约束。目前前端 `ResumePreview` 采用连续纵向滚动渲染，缺乏任何 A4 打印尺寸基准指示：
1. 用户在编辑或生成时无法得知当前内容是否已溢出至第二页。
2. 往往在点击导出 PDF 之后才发现多出了几行孤行或空白第二页，造成排版体验断裂。
3. 前端 DOM 渲染与后端 ReportLab PDF 的排版参数（边距、行高）缺乏一致性验证保障。

## What Changes
1. **A4 分页标尺与指示线**：
   - 依据标准 A4 宽高比（1 : 1.4142）及渲染宽度计算物理页面断点。
   - 在每页末尾渲染可视化 A4 分页虚线、页码指示徽章（例如「第 1 页 / 共 2 页」）。
2. **目标页数与超页预警**：
   - 支持设置期望目标页数（默认为 1 页，可选 2 页）。
   - 内容溢出目标页时，顶部/分页处给出友好预警与排版精简提示。
3. **前后端一致性抽检测试**：
   - 抽检比对不同模板下测试用例在前端页面高度模型与后端 PDF 页数的一致率。

## Impact
- 影响范围：前端 `ResumePreview.tsx` 及容器包装组件，新增前后端一致性校验测试。
- 不修改底层数据库结构，不影响已有简历内容数据与 API 格式。

## Rollback
- 分页为前端纯展示层能力与测试用例，代码可独立回滚，无持久化破坏性风险。
