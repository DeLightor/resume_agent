# Specification: 预览分页与一致性校验 (US-34)

## 1. A4 纸张几何与高度计算
- 纸张宽高比：标准 A4 为 1 : √2 (297mm / 210mm ≈ 1.41421356)。
- 容器单页高度映射：$H_{page} = \text{round}(W_{container} \times 1.4142)$。
- 动态感知：使用 ResizeObserver 实时监听容器尺寸与内容伸缩。

## 2. 页面标尺与分页线
- 在 $k \times H_{page}$ 处自动渲染水平红色虚线。
- 居中悬浮药丸徽章：`✂️ A4 分页线 · 第 k 页结束 / 第 k+1 页开始`。
- 设置 `pointer-events-none`，确保文字选中、内联编辑与重新生成按钮点击完全不受任何遮挡。

## 3. 目标页数与超页预警
- 预览顶部常驻 A4 排版控制条，显示实际总页数与目标页数。
- 支持一键切换目标页数（默认为 1 页，可选 2 页）。
- 超页时动态触发琥珀色预警横幅，提示针对性精简建议。

## 4. 后端 PDF 编译页数对齐
- `pdf_builder.py` 导出接口响应头包含 `X-Page-Count`。
- `POST /api/export/page_count` 支持无需下载直接预估后端 PDF 物理编译页数。
- 单页简历抽检与多页超长简历在 ReportLab 编译输出与前端估算完全对齐。
